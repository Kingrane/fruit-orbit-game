Это полный чек-лист из официальных доков Яндекс Игр на май 2026. Модерация смотрит именно по нему. Если хоть один пункт не соблюден - реджект.

Как проходит модерация
Full-модерация - перед первой публикацией и при каждом изменении файлов игры. Тестируют билд. 3-5 рабочих дней. 

Content-модерация - если менялись только промо-материалы: иконка, обложка, скрины, описание. Билд не тестируют. 1-2 рабочих дня. 

A/B тест иконок тоже проходит content-проверку.

Если отказ: приходит коммент модератора в консоли + письмо на почту Yandex ID со скринами/видео нарушений. Попыток бесконечно, но кулдаун удваивается после каждого отказа. Максимум 384 часа / 16 дней. Кнопку Moderation cooldown reset можно нажать 1 раз в 28 дней. 

Самые частые причины отказа: не переведен интерфейс, неправильная реклама, тех-ошибки, несовпадение названия в игре и черновике, возрастной рейтинг, обрезанный интерфейс, клон другой игры. 

1. Технический мастхев
SDK - обязательно:

Yandex Games SDK установлен и инициализирован ТОЧНО как в доке Connection and usage. Должен быть новый загрузчик, в дебаг-панели это IT (init true), а не IF. Проверяется добавлением &debug-mode=16 к адресу. 
В момент когда игрок может начать играть (появилось меню или управление) - вызвать LoadingAPI.ready() из Game Ready. Индикатор в дебаг-панели должен стать зеленым именно в этот момент, не раньше и не через пару секунд. 
GameplayAPI.start() / stop() - опционально, но если используешь - должны четко совпадать с началом/концом геймплея, паузой, открытием меню, магазина, рекламы, потерей фокуса вкладки. 
ysdk.on() / off() для game_api_pause и game_api_resume - тоже по доке если используешь.
Авторизация только после добровольного действия игрока, с понятным объяснением зачем. Можно логин через Yandex ID, но нельзя требовать регистрацию в сторонних сервисах для запуска. Должен быть гостевой режим без логина, и прогресс в нем должен сохраняться. 
Звук, платежи, реклама:

При сворачивании вкладки на десктопе и мобиле - звук стопается. 
Платежи ТОЛЬКО через Yandex Games SDK. 
Реклама ТОЛЬКО через SDK. Нельзя менять вид встроенных блоков и имитировать свои фуллскрины/RV своими кнопками. 
YAN-монетизация включена. 
Файлы и сборка:

Общий размер всех файлов в распакованном виде < 100 МБ. 
В корне архива index.html. Имена файлов и папок без пробелов и кириллицы. 
Нет абсолютных URL на S3 Яндекса в коде. 
Нет тех-способов ограничить игру по URL где она открыта. 
Нет тех-сообщений, ошибок, крашей, фризов при повороте экрана, лонгтапе, свайпах, сворачивании, показе рекламы, навигации назад. 
Игра полностью готова, не в стадии разработки/теста. 
Интерактивный AI запрещен. Материалы, заранее сгенеренные нейросетью - можно. 
Обновление должно сохранять кор-концепт. Нельзя загрузить совсем другую игру как апдейт. 
Кроссплатформа:
Должна корректно работать в: Yandex Браузер, Chrome, Firefox, Opera, Safari, мобильное приложение Яндекса. На Windows Vista/7/8/10, Mac OS X 10.6+, Android 5.0+, iOS 9.0+, Android TV. Тестируют в условиях реального юзера. 

Для мобилок:

Фуллскрин при запуске/геймплее.
Клавиатура появляется автоматом при клике на текстовое поле.
Нет искажений/растяжений при смене ориентации. Если поддерживаешь только одну - укажи в черновике, в другой покажется просьба повернуть.
Управление только жестами, можно акселерометр. Долгий тап не должен выделять текст и вызывать контекстное меню.
Нет WebGL-нотификации, нет системного плеера браузера. 
Для десктопа:

Активная область растягивается по вертикали/горизонтали под доступное место, не считая стики-баннеры.
Длинная сторона активной области не больше короткой в 2 раза.
Управление клавиатура/мышь. Нельзя перехватывать системные хоткеи ОС.
Взаимодействие с полем не вызывает выделения и контекстного меню. 
Для ТВ:

На весь экран, фуллскрин доступен.
Достаточно стрелок пульта, поддерживаются Back и OK.
Нет внутриигровых покупок.
Нет ссылок на другие игры разработчика. 
Общие UX-тех требования:

Сохранение сразу после действия или по кнопке Save. Обновление страницы не сбрасывает прогресс. Если сохраняешь в облако - укажи в черновике что именно. 
Рендер корректный, ничего не обрезается границей игровой зоны, при ресайзе окна все ок. 
Нет системного скролла страницы и swipe-to-refresh. Свой скролл внутри игры можно. 
Элементы не перекрывают друг друга. 
Можно играть одной рукой, без доп скролла главной сцены. Исключение: стратегии, RPG с большой картой. 
Размеры кнопок/элементов адаптированы, чтобы избежать случайных нажатий. 
2. Покупки, если есть
Включен метод consumption.
Название и иконка портальной валюты берутся из SDK. 
Прогресс сохраняется на сервере и доступен на разных устройствах. 
У всех покупок указана цена цифрой + название валюты.
Картинка, название, состав покупки = тому что получит игрок. 
3. Реклама
Нет рекламы сторонних рекламодателей, включая статические картинки и текст. 
При клике на рекламу и возврате - прогресс сохранен. 
Ориентация всех рекламных блоков совпадает с ориентацией игры.
Реклама не мешает геймплею, показывается только на логических паузах. 
Rewarded: игрок сам хочет смотреть (кнопка), четко написано что он смотрит рекламу за награду и какая именно награда. Награда - это экстра-бонус (бустеры, доп ходы, пропуск уровня), а не возможность продолжить играть. 
Доп блоки - только sticky баннеры. Кастомные RTB баннеры запрещены.
Во время фуллскрина и RV - звук и геймплей на паузе. 
4. UX и контент игры
Игра качественная по геймплею, удобству. Яндекс может отказать если не пройдет quality check. 
В игре или описании есть полное описание управления. 
Жанр совпадает с выбранным. Есть хотя бы одна игровая механика. 
Если есть сюжет/уровни - прогресс сохраняется. Если endless/highscore - сохраняются рекорды. 
Возрастной тег соответствует контенту. 
Сложность растет постепенно, сюжет/сеттинг понятны. 
Геймплей >10 минут. Для казуалки 10-20 уровней, для квиза минимум 100 уникальных вопросов (не рефрейзы одного и того же), для пазла - несколько заданий. 
Локализация хотя бы на один выбранный язык. Рекомендуют русский для RU/BY/KZ/UZ/UA и английский для остальных. Автоопределение языка через SDK. 
Рейтинг >30. Если 3 недели держится 30 или ниже (или нет оценок) - снимут с публикации.
Нет багов мешающих использованию.

Эротика и неприятный контент - самая частая причина бана промо:

Порнография и призывы к обнажению, механика раздевания - запрещено везде, и в игре тоже. 
В промо запрещен: основной фокус на эротике, эротический антураж (силуэты на фоне кровати/дейтинга), упоминания секса, цензура кружочками 18+, сексуализированное раздевание/нагота, имитация половых органов/груди и их силуэты, эротический кликбейт, эротика в заголовке/описании. 
Принцип: если в 2+ материалах есть намеки на эротику - откажут. Если только в 1 материале легкий намек - могут пропустить. 
Туалетный контент: фекалии как главный контент даже в милом стиле, процессы мочеиспускания/дефекации, Skibidi Toilet как главный контент, неприятные слова в текстах - все это бан. Допустимо только как фон, не реалистично, не фокус. 
Шок-контент: реалистичные маргинальные группы, бомжи, преступники, увечья, болезни, трупы/скелеты (кроме фэнтези где это часть жанра), мутации/зомби/монстры как фокус вызывающий сильный страх/отвращение - бан. Упрощенный, нестрашный, дружелюбный стиль может быть допущен если это не основной фокус. 
5. Требования к описанию и промо-материалам
Заполнить обязательно: Title, Description, How to play, Version, Categories, Icon, Cover, Sources, Supported platforms, Orientation. Скрины по инструкции. 
Тексты и промо-файлы соответствуют стандартам по длине, размеру, формату, длительности из формы черновика. Тэги/ключевые слова соответствуют теме. 
Нельзя использовать скриншоты игры как иконки/обложки. 
Все медиа могут иметь черные поля по бокам/сверху-снизу только если это часть игры, а не заливка из-за масштабирования.
Нельзя накручивать длину текста пробелами/дефисами и дублировать тексты в разных полях. 
Название в каталоге уникально для всех выбранных языков.
Название игры для каждого языка идентично во всех местах: в самой игре и во всех материалах черновика. 
Промо-материалы: используются элементы из представленной игры или прямо связанные с ней. Запрещено использовать геймплей из других игр и одинаковые промо в разных играх.
Скриншоты: минимум 70% - реальный геймплей. Остальное - рамка/эффекты. Тоже самое для видео, кроме рекламных. 
Материалы должны показывать о чем игра, фишки, преимущества.
Текст и медиа-контент общие:

Грамматика/пунктуация ок, не вводит в заблуждение, отражает реальную механику. Значимые для геймплея тексты переведены на выбранный язык. Нет мата ни на каком языке, нет запрещенных материалов. 
Хорошее качество, без артефактов сжатия, теней, монохромных кадров, обрезанного текста в иконках/обложках.
Контент отражает объект (иконка/обложка/покупка). Не рандомная картинка.
Нет рамок и скругленных углов.
Нет системных элементов: статус-бар, батарея и т.д. Нет элементов UI Яндекс Игр: бейджи, рейтинг и т.д. Игровой UI можно, но не на иконках/обложках. 
Нет порно/эротики/имитации органов/ссылок на секс, нет оскорблений по полу/нац/религии. 
Контент безопасный, этичный, suitable for all ages, иначе могут не фичерить на главной или отказать.
